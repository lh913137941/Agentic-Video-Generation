# 视频工作台 UI：与《即梦 AI 视频智能编辑：快速体验操作指南》的交互映射

参考材料：用户资料库内《即梦 AI 视频智能编辑：快速体验操作指南》，2026-10-10 版。这是对其操作流程的借鉴，并非连接即梦 AI，也不构成对即梦现有账号、模型或功能的保证。

## 交互映射

| 体验指南环节 | 我们的 UI | 完成度 |
|---|---|---|
| 选择“视频生成”或“智能编辑” | 独立的「智能编辑 · 已有视频」与「剧本成片」 | 已实现 |
| 上传 5–10 秒 MP4 | 原视频上传与预览；API 校验真实 MP4；上限 30 秒/100 MiB | 已实现 |
| 输入修改提示词 | 白天→黄昏 / 物体替换 / 移除物体 / 镜头运动模板 | 已实现 |
| 生成新视频 | 视频上传后以 input_reference 调用 vLLM-Omni 异步 V2V | 接口实现，模型兼容尚未实机确认 |
| 对比原片与结果 | 原片与结果并排展示，状态轮询 | 已实现 |
| 导出视频 | 结果 READY 后展示 MP4 下载链接 | 已实现 |
| 高级区域框选 / 时间帧 | 折叠区明确“规划中” | 未实现 |

指南中“白天改黄昏”指令的“人物身份、服装、动作、镜头节奏和时长不变”属于模型收到的期望，不是系统保证。不要通过无条件重生成冒充基于原片的编辑。

## 信息布局

顶部描述模式差别。智能编辑默认页左侧是原素材、编辑指令和“生成”操作，右侧是原片 / 结果对比、任务状态和下载。剧本成片页左侧文案、风格及分镜数，右侧粗剪预览，下方逐镜头编辑、重投。任务错误显式展示。编辑模式 Mock 拒绝，而非虚假生成。

## API 与能力边界

- POST /api/video-edits 接受 multipart 视频文件与 prompt；返回 202、任务 ID。
- GET /api/video-edits/{id} 查询状态；/source、/result 供预览与下载。
- GET /api/capabilities 说明当前部署是 Mock 还是 Omni，以及区域/时间编辑是否实现。
- 源 MP4 校验上传大小、容器、ffprobe 视频轨及片长。
- 多项目共用 GPU 并发信号量；重启时标记未完成编辑失败。
- 当前不提供区域绘制 Mask、精确时间段控制、声音同步、费用预测和真实模型编辑质量保证。
- API 仅绑定本地回环地址；公开部署需要鉴权和上传隔离。


## Mock 模式的防误操作（2026-10-10）

截图反馈显示，先前 Mock 模式下「生成编辑结果」可点击，但 API 必然返回 409。新版 UI 首次进入时默认禁用智能编辑提交，等待 GET /api/capabilities 检测；API 不连通或 Mock 模式时，仍禁用按钮并说明需要部署实际 Omni/V2V 模型，用户可使用「剧本成片」继续验证现有 Mock 流程。

- 「↻ 重新检测后端能力」可在重启并切换模型后刷新按钮状态，无须清空已输入的原视频和提示词。
- 配置 Omni 后，提交按钮才启用，但界面必须明确「已配置不代表模型 V2V 兼容性已验证」。
- 即使绕开 UI，API 仍以 409 拒绝 Mock 编辑请求；失败关闭是正确的安全边界，而不是需要放开的 Mock 功能。

## 创作工作台视觉与交互重构（2026-10-10 第二轮）

针对用户反馈「下拉选框只有一个当前选项、还需点击使用模板、视觉比较粗糙」：

- **移除编辑模板下拉框与多余确认按钮**：改为 4 张可直接点击的灵感卡片（光影氛围、替换物体、清理画面、镜头运动）。单击立即填入完整 Prompt，文本框可自由修改。
- **重新梳理视觉层级**：深色品牌页眉、二级模式导航、横向四步引导、白色编辑分区及统一间距、清晰的主次按钮。
- **智能编辑左右创作布局**：左侧上传原视频 → 灵感卡片 → 指令编辑 → 能力检测和提交；右侧原片/结果双栏对比，未生成时呈现明确的空状态。
- **任务状态可见**：等待提交、排队中、生成中、已完成、失败五类状态，成功后提供独立导出链接；Mock 模式时生成按钮不可用。
- **剧本成片页同步统一**：剧本、粗剪预览与分镜编辑卡片采用相同视觉语言，保留原有单镜头重投。
- **响应式样式独立文件**：src/agentic_video/assets/studio.css，通过 setuptools package-data 打包，避免内联 CSS。

不新增后端接口，不把未验证的 V2V、区域 Mask、时间段编辑包装成已经支持。UI 视觉不依赖在线图片或收费组件。

验收：Mock 模式可浏览编辑界面但生成提交禁用；四张模板卡片直接填入提示词；剧本成片可继续使用；Gradio 构建、卡片数量及 HTML 转义接受自动化测试。


### 模板选中反馈

灵感卡片单击直接更新 Prompt，同时将选中卡片切换到高亮态，其他卡片恢复普通态；正文与选中说明同步更新。默认高亮“白天变黄昏”。切换只改变文本草稿，不会自动提交视频生成。测试覆盖卡片选中互斥与无效模板拒绝。


## 统一创作工作台（后续重构）

原本的双 Tab 页面、左侧分镜表单和右侧结果区已经由单页对话式创作框取代。为避免混淆，本文件前文记录的是此前 UI 设计迭代历史，**不再是当前首屏布局的准确描述**。当前实现以 [单页对话式创作工作台设计](unified_workspace_design.md) 为准。后端 V2V 限制和即梦体验指南中的“目标时长/对象保持”仍不构成能力保证。
